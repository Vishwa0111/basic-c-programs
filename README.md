# Basic C Programs

This repository contains basic C programming practice programs developed while learning C programming.

## Topics Covered

- Basic input and output
- Variables and data types
- Operators
- Conditional statements
- Loops
- Number-based programs
- Digit operations
- Mathematical programs
- Basic problem-solving programs

## Programs Included

The programs are organized using filenames such as:

- `p01.c`
- `p02.c`
- `p03.c`
- `p04.c`
- `p05.c`
- `...`


## How to Compile and Run

Compile a program using GCC:

```bash
gcc p01.c -o p01
